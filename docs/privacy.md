# ベータ版のデータ取扱い

更新: 2026-09-07 / 対象: `0.1.0-beta.1`

この文書は実装に基づく説明です。運用者名、連絡先、公開URL、サーバーの設置地域、ログ・バックアップの保持期間はまだ確定していません。一般公開前に実際の運用と一致させ、利用者が参照できるプライバシーポリシーとして確定する必要があります。

## どこに何を保存するか

| 場所・操作           | データ                                                                             | 目的                               |
| -------------------- | ---------------------------------------------------------------------------------- | ---------------------------------- |
| この端末             | 工房名・表示名・設定、動画、抽出画像、メモ、質問と回答、技術Wiki、改訂、未記録質問 | 作業の記録、再開、技術の参照       |
| アカウント作成       | メールアドレス、表示名、チーム名、パスワードから作るハッシュ                       | チームへの認証・参加               |
| チーム共有           | 利用者が送信した記録、回答、下書き、Wiki、動画、改訂、質問                         | チーム内の技術継承                 |
| AIの解析・生成・検索 | その処理に必要な抽出画像、メモ、回答、観察、検索文、確認済み知識                   | 判断点への質問、整理、根拠付き回答 |

端末内保存はIndexedDBを使います。パスワードは端末へ保存せず、セッションはアプリのメモリに保持します。サーバーはパスワードとセッショントークンのハッシュを保存します。再読み込み後の再ログインが必要です。APIキーはサーバーの環境設定だけで扱います。

この実装に広告や行動分析用のSDKは含めていません。ただし、公開するホスティング環境やプロキシが記録するIPアドレス・アクセスログ等は別です。運用者は実際に収集するログをこの文書へ追記します。

## 送信を選ぶ

通常の記録は端末内に保存します。チームへ送信する操作と、AIへの送信を有効にする設定は別です。チームにログインしただけで端末の全記録を同期しません。サンプル資料を共有データに含めません。

AI解析が扱う映像入力は最大12枚の抽出画像です。動画本体や動画の音声をAIへ送って分析する実装ではありません。端末キーボードの音声入力を使う場合は、そのOSや入力サービスのデータ取扱いも適用されます。

AIは設定されたサーバー経由でOpenAI Responses APIを使います。リクエストに `store:false` を指定していますが、これだけで外部サービスの一切の保持がなくなるとは説明しません。OpenAIの公式説明では、APIデータは明示的に提供を選ばない限り学習に使用されず、通常の不正利用監視には別の保持条件があります。実際のAPIプロジェクトの契約・設定と[公式のデータ管理説明](https://developers.openai.com/api/docs/guides/your-data)を確認してください。

AI送信を無効にしても、既に送ったデータを外部サービスから取り消す操作にはなりません。撮影される人や機密情報を、選んだ共有先に送ってよいかは送信前に確認してください。

## 誰が読めるか

サーバー上の記録・動画はチームに所属するアカウントから取得します。共有した下書きや回答もチーム内で見られます。「Wikiへ公開」は現在のチームの知識として使う操作であり、インターネットへの一般公開機能ではありません。

共有サーバーの運用管理者は保存領域へアクセスできます。このベータは端末間のエンドツーエンド暗号化を実装していません。保存ディスクの暗号化、運用者のアクセス制御、HTTPSは配布先の運用で整える必要があります。

## 消去と退会

| 操作                           | 消えるもの・残るもの                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 端末の記録を削除               | この端末の対象記録。共有済みの記録は自動では削除しない。                                                   |
| 端末の全消去                   | 端末の記録・動画・設定。共有先と、書き出したバックアップは残る。                                           |
| ログアウト                     | 現在の接続。端末の記録は残る。サーバーに到達できれば現在のセッションを無効化する。                         |
| アカウント削除                 | 認証情報とセッション。他のメンバーがいる場合、チームの共有記録は残る。管理者なら別のメンバーへ管理を移す。 |
| 最後のメンバーのアカウント削除 | チームとその共有記録・動画も削除する。端末内の記録と外部へ書き出したコピーは残る。                         |

共有済み記録を個別に削除する利用者向けの手続きは、運用開始前に管理者が定めて公開します。APIには、共有記録から参照されていない動画を削除する機能があります。退会・削除はバックアップ媒体の即時物理消去を保証しません。運用上のバックアップから削除する時期と復元時の扱いも、公開ポリシーで決める必要があります。

## 書き出しと保持

JSONバックアップは技術の文章と根拠情報を含み、動画本体・フレーム画像・パスワード・設定は含みません。Markdownも元動画の代わりにはなりません。書き出したファイルの保管先と第三者への共有は、書き出した人が選びます。

端末の故障、アンインストール、OSによる保存領域整理で、ローカル記録を失うことがあります。元動画と文章の両方を保管してください。サーバー保存には自動の期限削除を設けていません。サービス終了時の返却、保持期間、バックアップ・復元は運用者が確定します。

ネイティブ権限とOSバックアップに関する宣言は [mobile-release.md](mobile-release.md)、サーバー実装と削除条件は [server/README.md](../server/README.md) を参照してください。
