# ベータ基盤から申請準備を終えるまで

更新: 2026-09-07

今回の到達対象は、実記録から技術継承まで進めるアプリと、iOS/Android配布へ進める基盤である。**ソース・設定が揃っている状態と、署名したアプリを申請できる状態を区別する。** 下記の未完了項目が残る間は「申請するだけ」と説明しない。

## 同梱済みの基盤

- 日本語の主要フロー、端末保存、根拠と確認状態、バックアップ。
- 認証付きAPI、SQLite、チームごとの映像、競合検知付き同期、OpenAI接続。
- iOS・Androidプロジェクト、権限・アイコン・配布前点検、ビルド用CI設定。
- 単一サービス用のDockerfileとCompose、永続データの分離。
- 製品の受け入れ条件、3分デモ、デザイン、事前開発の開示、データ取扱いの草案。

これは同梱内容の一覧であり、実機・クラウド・ストアの試験完了を表すものではない。検証した日時・対象コミット・端末・結果を、配布する版に対応付けて残す。

## 確認する一周

1. 新しい端末で、自分の動画またはメモから記録を作る。
2. 3問のうち一つへ固有の判断を追記し、途中で閉じても回答を復元できるか試す。
3. 下書きに回答が反映され、回答原文または映像時刻へ戻れることを確認する。
4. 全ての主張を確認して公開し、編集で承認が外れることを確かめる。
5. 後輩として質問し、必要な条件に出典付きで到達する。未知条件には確認が必要と返ることを試す。
6. 二つの端末で共有し、同時編集時に黙って上書きされないこと、別チームから読めないことを確認する。
7. JSON・元動画を保管し、読み戻し、退会、端末消去後に何が残るかを照合する。

細かなSDK・署名・OS権限の手順は [mobile-release.md](mobile-release.md) に集約する。`mobile-preflight` の成功だけでこの一覧を完了にしない。
