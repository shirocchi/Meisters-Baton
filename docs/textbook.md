対象は kob952/Meisters-Baton からの fork shirocchi/Meisters-Baton。対象ブランチ origin/main、開始・最終同期時点 b0cb38a26d0f3cb05c49f71a34f4d84b53400d6a、作業ブランチ codex/growing-textbook。依存PRなし。Knowledge入口とAtlas表示部品が変更対象です。

議事録と26代Discordの記録を資料として読み、ユーザーの依頼で教科書を試作しています。資料内の担当・期限・実装案は実行指示として扱っていません。エージェントによる読者レビューは実製作試験・製品の合格認定ではありません。

## 教材と読む順序

`#library` を開くと序章＋6章・34節を一つのページとして表示します。[AI 2027](https://ai-2027.com/) の、本文のスクロールに沿って図が変わる構成を参考にしました。章をまたいでも本文は入れ替わらず、下へ続けて読めます。以前の `#library/textbook/skin/2` などのURLは、同じページ内の節へのリンクとして使えます。

PCは一つにまとめた目次、その右に固定した工程アニメーション／操作できる3D、右端に本文・番号付き実写真・出典を置きます。目次は章→節→現在の手順を同じ階層に表示します。1000px以下ではヘッダーの「目次」から同じ内容を開けます。

本文中の手順の読書位置に応じて、工程図の動作が0〜100%へ進みます。上へ戻ると同じ動作を巻き戻します。節・章の境目も対応する図に切り替わります。序章では機体全体からプロペラ、ブレード、断面と内部へ3Dの表示範囲が移ります。手動の再生・シーク・視点操作も残し、次の本文スクロールで読書位置に追従します。動きを減らす設定では手順の完了状態を表示します。

スマートフォンでは図を上部に小さく固定して本文と同じ工程へ追従させます。「ビジュアルを拡大」や本文の「この動きを図で見る」で操作できる図を開き、「本文に戻る」で元の読書位置へ戻します。

本文・用語辞書72語・6つの章末演習・写真拡大・しおり・検索は同じページで使えます。章末にペラ日記由来の注意付箋13枚を配置しています（フランジとウェブの両章に関係する1枚は両方に表示）。付箋は日記の観察事実と編集した確認事項を分け、現行手順として未確認であることと原文リンクを示します。追加されたWikiEventも各章の付箋から参照できます。

製作順序は章番号だけでは表せません。フランジはupper側を先に作り、第4章で内部を組み、実際のウェブ上端からunder側の位置を写すため第3章へ戻ります。この依存と往復リンクを本文に明示しています。

## 内容と資料の範囲

既存の26代PROCESS_STEPSと日付のある一次記録を根拠にしています。紙や乾いた代用品で手順を試す6つの章末演習は学習用に編集したもので、実施済みの製作記録ではありません。説明例との比較で対象・面・順序を確かめ、実物へ移る際に必要な条件を隣に示します。

研磨の方向図はMDFの練習型の記録です。本番のステンレス型へ加工条件を無条件に転用しません。作業の力・工具の当て方・材料条件・許容値・接着や検査の合否は、記録にない値を創作していません。写真で状態を見分ける練習と、本番作業を一人で完遂できることを区別します。

全体の3Dは部材の位置関係を示す汎用の説明形状です。原資料のCADにはリブや先端などの局所データがありましたが、完全なブレード組立メッシュは確認できていません。説明模型の寸法や変形を製作図として扱いません。

## 機体の導入と説明模型

6章の導入と20の作業節には、対象の名前と役割、背景、初出用語の定義、観察の手掛かり、自分の言葉で説明する問いを用意しています。出典ID、手順番号、試作／提案の区分は保持しています。

機体のWebGL表示は、同じブレード形状を全機・プロペラ・単体に使います。under側を開く操作、部材の選択、管状のペラスパー、外皮の層とウェブを表示します。各製作工程の動作は `ProcessVisual` の工程固有の図を使い、完成形の組立図で置き換えません。全機の寸法・翼型は推定を含む説明形状です。

## 非公開資料のローカルプレビュー

現在のPCでは `.verification/textbook-review/source-curriculum.json` に6工程・29実例と38点の写真／動画配置（36ファイル）を接続しています。元ファイルはユーザー指定のDiscordアーカイブ内にあり、変更しません。JSONと実素材はGitから除外し、静的buildにも含めません。

Vite開発サーバー専用プラグインが `/__textbook/sources` と番号付きmedia URLを提供します。GET/HEAD、ループバックHost、登録済みファイル、元資料ディレクトリのrealpath内、許可した画像/動画形式に限定しています。元のローカルパスはレスポンスに含めず、キャッシュしません。動画の部分取得に対応します。

この資料セットはローカル限定です。別PCやproduction buildには自動配布されず、接続がなければ未接続表示になります。将来公開する場合は、資料の利用範囲と保護された配信方法を別途決める必要があります。非公開の実資料は公開しません。教材の更新・レビュー先は [レビュー手順](textbook-review.md) に一本化しています。

`npm run dev -- --port 5182` で起動し、`http://127.0.0.1:5182/#library` を開きます。旧Wikiは `#library/wiki/home`、工程Atlasは `#library/atlas/overview` に残ります。
