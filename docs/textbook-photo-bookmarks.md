# 写真のしおり

ユーザーが指定したプロペラ班Discord資料から、製作の説明に対応する写真・図解71点を選定し、本文の手順へ差し込みました。選定画像の掲載は2026年9月13日のユーザー依頼によります。

| 配置先               | 写真・図解 |
| -------------------- | ---------: |
| 型づくり             |         15 |
| 外皮・コア・バギング |         21 |
| フランジ             |          7 |
| 内部部材             |          8 |
| 貼り合わせ           |         12 |
| 仕上げ               |          7 |
| 機体全体             |          1 |

71ファイル・本文72配置です。ウェブの組立写真1点は、内部構造を紹介する序章でも使います。完成後の外皮は脱型の手順へ、型を取り出した写真は脱型へ、フランジ端のずれは積層後の確認へ配置しました。

出典とキャプションの正本は `src/components/book/photoSources.json`、配信画像は `public/textbook/photos/` です。元の投稿本文や人物一覧は同梱せず、キャプション・作業日・原記録リンクを持たせています。Exif等を除去し、向きを補正した長辺1600px以内のWebPとして保存しました。原本のVaultには変更していません。

画像は遅延読み込みし、PCでは同じ記録の写真を並べ、スマートフォンでは縦に並べます。すべて拡大可能です。試作・完成後の観察・提案図を説明で区別し、写真だけで原因や作業の合否を決めません。
