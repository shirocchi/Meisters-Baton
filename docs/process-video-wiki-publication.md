# 生成した工程解説を既存Wikiへ掲載する

対象ブランチは `main`、基点は `b65ccdbf26b30db3c66067b90b72a75a5f244fe8`。作業ブランチは `codex/process-video-wiki-loop`。前提のPR #26（動画生成）と #27（追加質問）は統合済み。重なる領域は `ProcessVideo`、Wiki添付契約、`WikiProvider`、動画生成API。公開・本番保存を実行する変更ではなく、その操作をアプリに実装する変更。

## 変わる体験

従来は生成MP4が端末内にとどまり、Wikiへ残すには別途ダウンロード・添付・編集が必要だった。作業記録でMP4を書き出すと、既存Wikiのページと工程を選び、説明・元の記録・出典を確認して掲載できる。既存本文を保ち、工房の非公開動画と編集履歴を使う。本文内で再生し、場面の時刻へ頭出しできる。

1. 記録へ動画・メモを保存し、必要な質問と追加回答を残す。
2. 「作業の3D解説動画を作る」で構成を確認してMP4を書き出す。
3. 「この動画をWikiの工程へ残す」でページ・見出し・説明を選ぶ。
4. プレビューの記録・判断・出典を確認し、「確認した内容でWikiへ掲載する」を押す。
5. 掲載したWikiで再生・場面の頭出し・元記録への復帰を確認する。

スマートフォンでは、解説動画の再生・頭出し時に浮動の工程モニターを最小化し、動画の操作部を隠さないようにする。モニターは通常の展開ボタンで戻せる。

## データと競合

- `ProcessVideoRun.recordingFingerprint` はメモ・回答・選択画像・解析の正規化JSONのSHA256。オブジェクトのキー順や元動画の共有ID変更では変わらず、内容変更では変わる。旧形式の動画は引き続き端末で再生できるが、掲載には再生成が必要。
- 添付は既存の `WorkshopMedia` に任意の `processVideo` を追加する。元記録ID、動画SHA256、実測尺、出典のID・参照版、場面時刻を保持する。既存添付・本文・履歴のデータベース形式を移行しない。
- 掲載前にMP4の実バイト・容量・ハッシュ・復号可能なメタデータを確認する。場面は実測尺内に収め、計画との差が0.15秒を超える動画は掲載しない。
- 既存の `save_wiki_page` RPCで元本文の版を比較し、他者の更新を上書きしない。取得できないページ・編集取得エラー・同名の見出しへは自動掲載しない。
- 同じ動画の二重掲載を拒否する。MP4の送信後に本文保存が失敗した場合は端末に送信先を保持し、再試行で再送しない。未掲載の送信済みファイルの自動削除はしない。本文保存に成功したか不明な場合は最新Wikiを取得して確認する。
- 記録やアカウントが処理中に変わった場合は、後続の保存・画面反映を止める。既存の工房認証とStorage/RPCのRLSを利用し、権限・バケットの公開設定は変更しない。

生成物は常に説明用の概念図として掲載する。製法承認済みの本文へ昇格させず、実写の証拠と区別する。保存した出典は生成時点の参照版であり、Wikiの新しい版と自動比較・再生成する機能は今回含まない。旧クライアントは追加メタデータを知らないため、旧版UIでの再編集は場面情報を保持しない可能性がある。対応アプリを同時に配布する。

## 検証の再実行

```powershell
npm run typecheck
npm test
npm run build
$env:VITE_SUPABASE_URL='https://wiki-test.supabase.co'
$env:VITE_SUPABASE_PUBLISHABLE_KEY='fixture-publishable-key'
$env:VITE_BATON_VERIFICATION='false'
$env:BATON_TEST_SUPABASE='1'
$env:BATON_TEST_PORT='5218'
npm run test:e2e
```

新しい `process-video-wiki.spec.ts` はAI構成・共有サービスを模擬応答にし、実際のH.264 MP4の描画・端末保存・送信バイト・本文保存・復元・頭出し・完走・390px表示を確認する。競合後の再試行、生成後の記録変更、プレビューのアクセシビリティも対象。自動反映を止める `VITE_BATON_VERIFICATION=true` では既存の自動反映試験が失敗するため、全件検証は通常設定で行う。すべての共有通信を試験側で捕捉する。

実アカウントでの新しい掲載操作、実動画への説明の正確さ、初学者の理解効果は別の検証であり、これらを模擬試験の成功から推定しない。現行の3Dは位置・回転を補間する概念図で、手・工具・変形の再現は未実装。
