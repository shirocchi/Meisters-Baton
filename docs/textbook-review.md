## 手元で開く

Node.js 22.13以降とnpmを使います。

```bash
git clone --branch codex/growing-textbook https://github.com/shirocchi/Meisters-Baton.git Meisters-Baton-textbook
cd Meisters-Baton-textbook
npm ci
npm run dev -- --port 5182
```

ブラウザーで `http://127.0.0.1:5182/#library/textbook/overview/0` を開いてください。教材本文・用語辞書・工程アニメーション・機体と部材の3Dは、Supabaseの設定なしで確認できます。既存Wikiのログイン機能を確認する場合は、元のREADMEに従って設定してください。

## 確認してほしい操作

1. 序章をスクロールし、本文に合わせて3Dが「機体全体 → プロペラ → ブレード → 断面と内部」と進むことを確認する。手動でも外皮を開いて部材を選べます。
2. 一つにまとめた目次の「内部部材を組む」を開き、4.1節とその手順へ移る。本文を下へ読み進め、図の動作も進むこと、上へ戻ると同じ動作を巻き戻せることを確認する。章の境目もページをめくらず進めます。
3. 本文の点線付き用語を開き、意味を読んで元の位置へ戻る。
4. ヘッダーの検索で「upper 桁」を探し、該当節へ移る。検索を閉じた後は、同じボタンからキーボードで再開できる。
5. 章末の演習を開き、手順を試してから説明例を表示する。図のわかりにくさ、説明の抜け、工程の誤りは、章・節・手順番号とともにPRへコメントしてください。

6. スマートフォンでは上部の小さな図が本文に追従します。拡大して操作し、本文へ戻ると読み位置が保たれることを確認する。
7. 各章末の「ペラ日記からの付箋」を開き、記録された出来事と編集した確認事項を読み分ける。出典の日付・Discordリンクを確認する。付箋は現行手順として未確認です。

## 写真・動画の扱い

GitHubには非公開Discordアーカイブの元画像・動画、ローカル資料JSON、認証情報を含めていません。通常のclone／buildでは写真が「資料が未接続です」と表示されます。元資料を接続したPCでは、6章29実例・38配置の写真／動画を本文に表示しています。

資料の読み込みは開発サーバーのループバック接続に限定しています。資料を閲覧できる人へ別途共有し、各PCで接続するか、認証付きの配信先を用意する必要があります。元資料を公開リポジトリの `public/` へ置かないでください。接続方式と現在の収録範囲は [textbook.md](textbook.md) に記載しています。
