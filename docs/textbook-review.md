## 手元で開く

Node.js 22.13以降とnpmを使います。

```bash
git clone --branch codex/growing-textbook https://github.com/shirocchi/Meisters-Baton.git Meisters-Baton-textbook
cd Meisters-Baton-textbook
npm ci
npm run dev -- --port 5182
```

ブラウザーで `http://127.0.0.1:5182/#library/textbook/overview/0` を開いてください。教材本文・用語辞書・工程アニメーション・機体と部材の3Dは、Supabaseの設定なしで確認できます。既存Wikiのログイン機能を確認する場合は、元のREADMEに従って設定してください。

## 確認してほしい操作

1. 序章をスクロールし、本文に合わせて3Dが同じ機体からプロペラ、一本のブレードへ連続して近づき、under外皮を開くことを確認する。手動でも外皮を開いて部材を選べます。
2. 一つにまとめた目次の「内部部材を組む」を開き、4.1節とその手順へ移る。本文を下へ読み進め、図の動作も進むこと、上へ戻ると同じ動作を巻き戻せることを確認する。章の境目もページをめくらず進めます。
3. 本文の点線付き用語を開き、意味を読んで元の位置へ戻る。
4. ヘッダーの検索で「upper 桁」を探し、該当節へ移る。検索を閉じた後は、同じボタンからキーボードで再開できる。
5. 章末の演習を開き、手順を試してから説明例を表示する。図のわかりにくさ、説明の抜け、工程の誤りは、章・節・手順番号とともにPRへコメントしてください。

6. スマートフォンでは上部の小さな図が本文に追従します。拡大して操作し、本文へ戻ると読み位置が保たれることを確認する。
7. 各章末の「ペラ日記からの付箋」を開き、記録された出来事と編集した確認事項を読み分ける。出典の日付・Discordリンクを確認する。付箋は現行手順として未確認です。

## 写真・動画の扱い

ユーザーの写真掲載依頼に基づき、指定されたプロペラ班Discord資料から製作に関わる写真・図解71点を選定しました。`src/components/book/photoSources.json` で工程・説明・作業日・原記録URLを管理し、`public/textbook/photos/` のWebP画像をGitHub Pagesでも配信します。ローカル資料を接続しないPCでも表示・拡大できます。

型の基準と下地、外皮・コア・袋の準備、フランジの位置、ウェブとスパー、貼り合わせ、ペラ端、塗装に割り当てています。写真は「写真のしおり」として該当手順内に置き、機体の全体写真だけは序章にも載せています。試作・完成後の状態・提案図を説明で区別し、写真だけで原因や合否を断定しません。

選定画像は向きを正し、長辺1600px以内のWebPに変換しました。EXIF等の付加メタデータを削除し、元画像・動画・全Discordログ・人物情報の一覧・認証情報は含めません。元のVaultには変更を加えていません。今回の公開範囲は選定画像と編集した説明です。

## アニメーションの参照

[共有されたアニメーション](https://chatgpt.com/s/cx_6aa69e21a734819180ccccfff5666357) の最初に表示される18秒のカメラ移動を、序章の読書位置に対応させています。機体全体での見やすさとupper内面の見通しのため、最初の距離と最後の回り込みを調整しました。同じ機体とブレードのメッシュを保持し、カメラ移動・機体と反対側ブレードのフェード・under外皮の開閉を連続させます。本文を戻れば逆にたどれます。

図の切り替えは直前の描画を短く重ねます。古い図の操作や読上げは無効にし、動きを減らす設定では即座に切り替えます。製作工程ごとの固有図は保持しています。参照資料内の私有CADや写真は複製していません。
