## 既存要素と第三者ツール

- アプリの主要基盤はReact、TypeScript、Vite、Capacitor。ローカル保存はIndexedDB、APIはNode.jsとSQLiteを使用する。正確な依存関係・バージョンは確定したロックファイルを参照する。
- AI機能は、利用者が設定したサーバー上のOpenAI APIを呼ぶ。モデルや外部サービス自体をチームが開発したと説明しない。
- 開発にCodexとGPT-6 Astraを使用。先行モックはCodex / GPT-5.6 Solによるもの。人間による製品判断・専門知識の確認と区別して説明する。
- デザイン作業では、公開されたfrontend-design skillの指針を参照。実装へ組み込む外部素材・フォント・コードはそれぞれの出典とライセンスを記録する。
- 初期サンプルは説明用データとして扱う。実際に撮影された工程の専門家承認、製造条件、利用実績の証拠として扱わない。

[第三者要素の一覧](third-party.md)に、利用パッケージ、フォント、素材、参照資料の出典を記録し、取得できたLICENSE/NOTICE原文を同梱した。npmの任意依存やOS・ネイティブ依存は、最終配布物に合わせた追加確認が残る。ロックファイルだけではデータ・素材・参照コードの開示を代替できない。提出用文書は、当日の追加要素と通知文を含めて確認してから確定する。
