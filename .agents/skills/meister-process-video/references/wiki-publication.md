# 生成した解説を既存Wikiへ残す

Meister's Batonの対応版では、作業記録 → 質問・追加回答 → 制作構成 → MP4 → Wiki掲載までを同じ記録で扱う。既存Wikiへ追加する依頼で独立した教材を新設しない。独立教材が指定された場合は、教材側の工程・出典・アンカーを引き継ぐ。

アプリでの入口は作業記録の「作業の3D解説動画を作る」。構成を確認してMP4を書き出すと「この動画をWikiの工程へ残す」が現れる。既存本文から掲載ページと工程見出しを選び、添える説明・元記録の判断・出典・未確認点をプレビューで確認する。

ユーザーが承認した共有範囲で「確認した内容でWikiへ掲載する」を使う。生成指示だけをWiki公開の承認と推定しない。未承認なら具体的な掲載プレビューを準備して判断を求める。既に掲載が承認されていれば聞き直さない。

生成動画は説明用の概念図であり、製法承認や一次証拠ではない。掲載は工房の既存の非公開保存先・編集履歴を利用する。元記録の回答と選択フレームの指紋が変わった場合は古い動画を掲載せず、作り直す。競合時は他者の本文を上書きせず最新を取得する。アップロード済みのMP4は再試行で使い回す。

掲載後、該当本文で動画の再生・場面の頭出し・出典表示・元記録へ戻る導線・再読み込みを確認する。実写元動画が端末のみなら他端末での再生は未確認とする。MP4のみから編集可能な3Dや本文に連動する模型を復元したと扱わない。

JSONの構成だけを返す `server/processVideo.ts` の呼び出しでは、この掲載操作を実行したと報告しない。実行実装は `src/components/ProcessVideoPublish.tsx`、`src/wikiState.tsx`、検証可能なデータ契約は `src/domain/processVideoWiki.ts` にある。
